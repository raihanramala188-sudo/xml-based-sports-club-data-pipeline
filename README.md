# XML-Based Sports Club Database Platform

## Project Overview

This project demonstrates an XML-based data pipeline developed as part of the Data Pipeline 1 course at DataScienceTech Institute (DSTI).

The platform manages structured sports club information using XML and demonstrates data validation, transformation and visualisation using Python, XSD, XSLT, HTML and JSON.

## Technologies Used

- **Python** – Pipeline automation
- **XML** – Structured data storage
- **XSD** – XML schema validation
- **XSLT** – Data transformation
- **HTML** – Data visualisation
- **JSON** – Structured data export
- **JSON Schema** – JSON validation

## Project Structure

| File | Description |
|---|---|
| `main.py` | Python pipeline automation |
| `sportsclub.xml` | Sports club dataset |
| `sportsclub.xsd` | XML validation schema |
| `bookings_schema.json` | JSON schema |
| `stylesheet_1.xsl` – `stylesheet_6.xsl` | HTML visualisation transformations |
| `stylesheet_7.xsl` – `stylesheet_8.xsl` | XML transformations |
| `stylesheet_9.xsl` – `stylesheet_10.xsl` | JSON transformations |
| `output_1.html` – `output_6.html` | HTML reports |
| `output_7.xml` – `output_8.xml` | XML outputs |
| `output_9.json` – `output_10.json` | JSON outputs |

## Pipeline Workflow

1. Load the sports club XML dataset.
2. Validate the XML document against the XSD schema.
3. Transform XML data using XSLT stylesheets.
4. Generate HTML visualisation reports.
5. Export structured XML and JSON outputs.
6. Validate generated data where applicable.

## How to Run

### Requirements

- Python 3
- lxml library

### Installation

```bash
pip install lxml
```

### Execute the pipeline

```bash
python main.py
```

Run the command from the directory containing `main.py` and the source XML, XSD and XSLT files.
